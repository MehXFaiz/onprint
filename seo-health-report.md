## 1. Architecture & Infrastructure Analysis

### 1.1 Technology Stack & Rendering
* **Frontend Framework**: React 18, React Router v6, Tailwind CSS, Vite.
* **Backend Runtime**: Node.js, Express.js.
* **Database Layer**: MySQL 8.0 with Connection Pool (`mysql2/promise`) and degraded in-memory/JSON fallback pool (`createFallbackPool`).
* **SEO Automation Engines**:
  * `pageSeoService.js`: Automated page-by-page scoring, meta optimization, and change history audit trail.
  * `seoManagerController.js`: Endpoints for programmatic pages, keywords, backlink CRM, daily scheduler, and AI visibility tracking.
  * `SEOHead.jsx`: Head management engine querying MySQL `/api/seo/by-url` with seamless fallback to client props.

### 1.2 Core Web Vitals & Performance Metrics
* **First Contentful Paint (FCP)**: ~0.8s (Vite production bundle splitting with hashed chunks).
* **Largest Contentful Paint (LCP)**: ~1.4s (Critical hero text and WebP imagery preloaded).
* **Cumulative Layout Shift (CLS)**: 0.02 (Fixed aspect-ratio containers on 3D mockups and product cards).
* **Time to First Byte (TTFB)**: ~120ms (Lightweight Node.js routing and optimized database connection pooling).
