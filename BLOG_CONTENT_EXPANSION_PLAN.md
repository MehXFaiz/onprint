## Content Guidelines

### SEO Best Practices
- Include primary keyword in title (first 60 characters)
- Include primary keyword in first paragraph
- Use keyword variations naturally throughout
- Include related keywords (LSI)
- Add internal links to relevant pages
- Add external links to authoritative sources
- Use H2 and H3 headers for structure
- Include bullet points and numbered lists
- Add images with alt text
- Include meta description (150-160 characters)
- Include URL slug with primary keyword

### Content Quality
- Provide actionable, valuable information
- Use data and statistics when possible
- Include real examples and case studies
- Add expert tips and insights
- Keep paragraphs short (2-3 sentences)
- Use simple, clear language
- Avoid jargon or explain it
- Include a clear call-to-action
- Add FAQ section with schema markup

### Formatting
- Use clear headings (H1, H2, H3)
- Use bullet points for lists
- Use numbered lists for steps
- Include bold text for emphasis
- Use italics for definitions
- Add tables for comparisons
- Include pull quotes for key points
- Add relevant images
- Include infographics when helpful

### Length Guidelines
- Comprehensive guides: 2,000+ words
- How-to articles: 1,500+ words
- Comparison articles: 1,500+ words
- List articles: 1,500+ words
- Industry updates: 1,000+ words
- Quick tips: 800+ words
